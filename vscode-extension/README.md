# LLM_Tuner

LLM_Tuner 网页上位机的 VS Code 外壳：

- 左侧活动栏图标 → 点击即用 **VS Code 内置浏览器**打开上位机面板（波形 / 参数 / 控制台）
- 同时起一个**只监听 127.0.0.1** 的本地服务，托管网页并给网页提供工作区源码读写接口
- 网页里的「工程」面板会自动连上这个服务（令牌已注入页面），无需手工配置

## 用法

1. 装好后点击左侧 **LLM_Tuner** 图标；
2. 侧边栏会出现启动面板，并自动在内置浏览器中打开上位机（可在设置 `llmTuner.autoOpen` 关闭）；
3. 想要串口：Web Serial 在 VS Code 内置浏览器里通常不可用，点「在系统浏览器中打开」即可，
   文件读写桥接两种模式共用。

## 命令

| 命令 | 说明 |
| --- | --- |
| `LLM_Tuner: 在内置浏览器中打开上位机` | 打开面板 |
| `LLM_Tuner: 在系统浏览器中打开（串口可用）` | 用默认浏览器打开 |
| `LLM_Tuner: 复制桥接令牌` | 独立部署网页时需要 |
| `LLM_Tuner: 显示桥接信息` | 端口 / 工作区 / 令牌 |
| `LLM_Tuner: 重启本地服务` | 改端口后重启 |

## 主题跟随

- 页面启动时扩展会把自己的配色方案（`window.activeColorTheme`）注入到页面里；
- 页面每 2 秒轮询 `GET /api/theme`，VS Code 切换浅色/深色时面板会跟着换（波形画布、坐标轴、图例、控制台一起变）；
- 右上角的 ◐ 按钮可切换：**跟随 VS Code → 浅色 → 深色**，手动选择会记住，选「跟随」即恢复同步。

## 设置

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `llmTuner.port` | 5173 | 本地服务端口（仅 127.0.0.1） |
| `llmTuner.autoStart` | true | 启动时开启服务 |
| `llmTuner.autoOpen` | true | 点图标自动打开面板 |
| `llmTuner.webRoot` | 空 | 自定义网页目录（默认用内置 `web/`） |
| `llmTuner.maxFiles` | 800 | 源码扫描上限 |

## 安全

- 服务只 bind `127.0.0.1`，不对外网开放；
- `/api/*` 全部要求 `Authorization: Bearer <令牌>`，令牌随机生成并存在扩展全局状态里；
- 所有文件路径限制在**当前工作区根目录**内，越界直接 400；
- 网页 HTML 里的令牌是同源注入的，第三方网站读不到（无 CORS 头）。
